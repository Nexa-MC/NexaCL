# NexaCL update source

This template is used by `Nexa-MC/NexaCL-Update`. Publish verified updates downloads a public source release, verifies actual assets and metadata using the pinned public key, and publishes the complete target version. The update source holds no signing private key and cannot overwrite public bytes of the same version.

[Source repository](https://github.com/Nexa-MC/NexaCL) · [Update releases](https://github.com/Nexa-MC/NexaCL-Update/releases)
