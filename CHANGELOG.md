# Release history

Maintainer-written release notes and signed assets are published on [NexaCL Releases](https://github.com/Nexa-MC/NexaCL/releases). Automatic updates use the [independent update source](https://github.com/Nexa-MC/NexaCL-Update/releases).

See [project documentation](docs/README.md) for current source structure and maintenance. Source changes do not replace published artifacts, and directory migration does not imply a new release.
