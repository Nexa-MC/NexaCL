# NexaCL Firefly Alpha 29

Version: `2.0.0.alpha.29`

## English

- Fix startup recovery for malformed settings version fields and Windows native window initialization before visual attachment.
- Preserve Unicode paths in exported Windows launch scripts and admit verified macOS system directory aliases in instance management.
- Verify segmented downloads before publication; reject inconsistent resume ranges and recover from source timeouts.
- Preserve resource-pack selections with UTF-8 BOMs, isolate invalid options, and keep writes within supported read budgets.
- Fix rejected offline texture registrations, server description arrays, theme busy-state updates, and log retention flush ordering.
- Improve signed release verification and recovery from transient artifact upload failures.

## 简体中文

- 修复设置版本字段异常时的启动恢复，以及 Windows 窗口挂载前初始化导致的异常。
- 修复导出启动脚本的中文路径兼容性，允许实例管理访问经验证的 macOS 系统目录别名。
- 下载分段合并后先校验再提交，拒绝不一致的续传范围，并在下载源超时后继续尝试其他来源。
- 保留带 UTF-8 BOM 的资源包选择，隔离无效配置，限制写入内容以确保后续可读取。
- 修复离线材质注册失败、服务器描述数组、主题忙碌状态刷新和日志保留策略的执行顺序。
- 改进签名发布校验，以及临时上传失败后的恢复。
