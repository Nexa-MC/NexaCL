# NexaCL Firefly Alpha 23

Version: `2.0.0.alpha.23`

## English

This hotfix restores startup with account files created before Alpha 22.

- Fix missing or null optional offline skin/cape fields being rejected during account loading. Existing accounts and credentials are retained; reading an encrypted legacy file does not rewrite it.
- Keep accounts unavailable, preserve the original file and allow startup to continue when persisted texture data exceeds its limit.
- Record native account exception types, status codes and stacks through the launcher log. Retirement failures report their cause once. Raw exception messages and credentials are excluded.
- Add regression coverage using literal old-format JSON, encrypted legacy files, asynchronous initialization and independent NativeAOT account runtimes, including Windows DPAPI storage.

### Restoring an account folder moved aside during troubleshooting

Install the complete fixed version and close the launcher. Move any newly created `profiles` folder aside, keeping its files, then rename your original `profiles.a22-backup` folder back to `profiles`. Start the launcher normally. No re-creation of existing accounts is required for this compatibility fix.

Windows, macOS and Linux x64/ARM64 distributions retain the separate native modules and bundled Market Sidecar. Keep the complete installation directory. Publisher GPG signatures are separate from OS code signing and notarization.

## 简体中文

本版修复 Alpha 22 读取旧账户文件时无法启动的问题。

- 修复新增的离线皮肤、披风字段缺失或为 null 时，被账户加载校验误判为非法数据的问题。保留原账户与凭据，读取加密旧档案不改写原文件。
- 对超限的已存材质数据，保留原文件并报告账户不可用，允许启动器继续启动。
- 将原生账户异常的类型、状态码和堆栈写入启动器日志；退役失败只报告一次原因。不记录可能包含凭据的原始异常消息。
- 增加真实旧格式 JSON、加密旧档案、异步初始化和独立 NativeAOT 账户模块回归，并覆盖 Windows DPAPI 读取。

### 恢复排查时改名的账户目录

安装完整修复版并关闭启动器。将新生成的 `profiles` 目录另行改名保留，再将原来的 `profiles.a22-backup` 目录改回 `profiles`，然后正常启动。本次兼容修复不要求重新创建原账户。

继续提供 Windows、macOS、Linux 双架构发行包，携带分离原生模块及配套 Market Sidecar。请保留完整安装目录。发布者 GPG 签名不等同于系统代码签名或公证。
