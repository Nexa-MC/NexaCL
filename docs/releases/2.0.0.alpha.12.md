# NexaCL Firefly Alpha 12 · v2.0.0.alpha.12

以 Alpha 11 为基线，继续 Alpha 预览阶段。

## 手柄入场预览

- 识别手柄后显示对应的手柄提示，左右摇杆向内推动并保持后进入全屏暗色画面。
- 新增从窗口平滑扩展至全屏、圆弧日出打光、图标拉远、NexaCL 标识和“手柄模式”字样依次出现的入场动画。
- 拉远阶段延长至 1.8 秒，保持圆弧位置稳定，动画采样跟随设置帧率，并遵循减少动态效果设置。
- **本次仅提供入场预览，尚未提供手柄模式内的游戏库、导航和启动操作。**

## 下载处理

- 修复依赖下载中 TLS/连接中断的错误归类，保留真实网络异常原因，避免将传输中断直接当作文件损坏。
- 完善中断传输与不完整文件的重试处理，继续复用可用下载缓存，并保留完成后的文件校验。

## 界面整理

- 精简设置页，移除无实际设置作用的条目、说明提示，以及网络诊断、目录清单、持久诊断历史和自动化示例等信息区块。
- 同步清理这些区块的页面专用读取与旧模板；代理、数据迁移、清理、备份及独立命令面板继续可用。
- 资源页底栏从 64 像素压缩至 28 像素，增加列表展示空间。追加加载的圆环与提示横向排列，已有条目与滚动位置保持稳定。

## 下载与更新

Windows、macOS、Linux 均提供 x64 / arm64 的 NativeAOT 构建。按系统和架构选择安装包或便携包；已有 Alpha 11 的受支持安装可在应用内更新，差分不可用时回退到经过签名校验的完整包。

Alpha 10 及更早便携版需先手动安装 Alpha 11 或更新版本，再使用应用内更新。测试预发布版本前请备份存档。

签名更新源：[NexaCL-Update](https://github.com/Nexa-MC/NexaCL-Update/releases/tag/v2.0.0.alpha.12)；源码与反馈：[NexaCL](https://github.com/Nexa-MC/NexaCL)。
