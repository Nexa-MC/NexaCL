# NexaCL Firefly Alpha 16 · v2.0.0.alpha.16

## 内置正式签名的 Market Sidecar

- Windows、macOS、Linux 的 x64 / arm64 发行包均内置 Nexa Cloud Market Sidecar 1.0.0。
- Sidecar 在独立仓库构建；每个平台的二进制均使用 NexaCL 正式发布密钥生成独立签名，启动器验签后加载。源码、账户及市场业务继续与 Host 分离。
- 支持 NexaMC 设备码登录：在客户端获取设备码，在网站核对并授权。密码和两步验证留在浏览器内完成。
- 账户页提供资料、账户管理入口及登录状态；市场支持插件／主题发现、详情及触底追加列表。

## 从网站安装主题

- 网站的“在 NexaCL 中安装”通过 `nexacl://` 唤起客户端，打开对应主题详情；未登录时先完成设备授权。
- 客户端核验拥有权、下载大小和 SHA-256，用户点击“应用主题”后通过 Host 的 NTP 校验与应用事务安装；下载失败会清理不完整文件。
- 网站不再提供主题文件下载。插件包上传与下载暂未开放，已有拥有权记录保留。
- 新增通用 Sidecar 页面唤起及用户确认的主题导入接口；外部链接不能指定命令、文件路径、下载地址或凭据。

## 发行与更新

提供六个平台／架构组合的原生安装包及便携包。正式签名覆盖内置 Sidecar、发行包和更新清单；更新源同步完整包及适用的差分包。Alpha 15 不支持新的市场协议入口，需要升级到本版。
