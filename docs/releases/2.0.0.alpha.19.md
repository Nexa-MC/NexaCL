# NexaCL Firefly Alpha 19

版本：`2.0.0.alpha.19`

本次以 Alpha 18 为基线，完成原生业务模块拆分，并补充整合包导出、文件关联和主题升级体验。

## 原生模块与更新

- 账户、网络与下载、Minecraft 管理及更新流程分别由独立原生模块执行；Host 统一检查模块版本并管理启动、取消和退出时的资源释放。
- 完整界面与渲染后端归入独立 UI 模块，继续提供无需安装 .NET 的 NativeAOT 构建。
- 更新包可复用未变化的模块；完整包、差分包和 Sidecar 继续沿用发布者签名校验，保留失败重试、中断恢复、完整包回退与回滚保护。
- 修复 PAC 配置准备与调用取消共用时限造成的误判，完善大文件流式传输、取消和连接释放处理。

## 整合包与实例管理

- 扩充实例整合包导出选项，支持目录 ZIP，并可选择携带游戏依赖；整合包导出仍按选定内容处理，保留文件校验、取消和临时文件清理。
- 完善压缩包与整合包文件关联，Windows 增加资源管理器右键安装入口；关联文件可交给已运行的启动器处理。
- 整理实例概览与整合包操作入口，修复缺少下载地址时的安装处理；失败阶段保留，便于继续或重试。
- 资源索引快照并列保存，避免不同安装任务互相覆盖；可恢复任务先持久化清除结果，再从任务列表移除。

## 界面、主题与桌面集成

- 相同 ID 的主题可直接升级；降级前显示版本确认，准备失败或取消时保留原主题。
- 恢复页面内控件的分批入场动画，调整整合包设置位置与离线准备进度展示；状态重载时保留分段选择和滑块的连续表现。
- 修复 Windows 从托盘及最小化状态恢复窗口时的位置和状态处理，完善 macOS 关闭时的原生回调释放。

## 下载与升级

提供 Windows、macOS、Linux 的 x64 / ARM64 安装包与便携包。此次首次调整完整模块布局，升级时请保留整个安装目录中的模块和资源，不要仅替换启动器 EXE。差分是否适用由启动器校验后选择。

全球正版资格校验和既有地区下载政策保持不变。发布者 GPG 签名不等同于 Windows Authenticode、macOS Developer ID 或公证。
