# NexaCL Firefly Alpha 18

版本：`2.0.0.alpha.18`

- 修复 AuroraGlass 等主题启用循环动画后窗口未响应：下一帧统一由动画时钟调度，画面提交不再触发无限刷新，输入事件可以正常执行。
- 修复 Minecraft 26.3 等新版清单中的 LWJGL 原生 JAR 被排除出 classpath，导致找不到 `lwjgl.dll` 的启动失败；保留旧版原生库处理。
- Microsoft 账户启动前刷新令牌遇到瞬时网络中断时有限重试；网络失败保留账户，不再误导用户重新添加。
- 本地资源索引缺失或校验失败时显示具体文件与补全指引，地区下载政策保持不变。
- 更新正式签名的 Market Sidecar：持久化账户会话和资料，断网保留登录状态；登录提供完整阶段提示、取消与重试，点击登录后自动复制设备码并打开授权网页。
- 市场页调整分类、搜索和卡片布局，连续追加列表保持滚动位置，详情返回保留列表。
- 修正架构检查在缺少构建依赖时产生文案误报的问题；共享 XSR 包新增版本化交付与显式启用的构建工具。

提供 Windows、macOS、Linux 的 x64 / ARM64 构件；便携版更新继续使用签名校验与差分更新。安装包、签名和更新源以本次 Release 完整构建验证结果为准。
