# NexaCL Firefly Alpha 27

Version: `2.0.0.alpha.27`



## English

This release simplifies instance settings, improves local file access and server discovery, and updates the Windows installers.

- Bundle the Liuli theme, including page-aware motion and material refinements for account actions and version selection.
- Accept the known read-only conditional ACLs added by Windows sparse MSIX registration during protected update admission. Writable or unknown conditional rights, untrusted owners and unsupported ACE types remain rejected. Verify real NativeAOT helper admission after default and opt-in installer flows on Windows x64 and ARM64.
- Remove the generic file/NBT viewer from all content details and the instance navigation. Remove the server requirements/environment editor. Named launch profiles and temporary overrides are visible only in instance development mode.
- Discover LAN games automatically while the Servers page is open. Show unique discovered endpoints alongside saved servers as “LAN server <address>”, with direct joining and no separate discovery prompts or buttons. Discovery does not write temporary endpoints to `servers.dat`.
- Import and open regular files reached through valid symbolic links or directory junctions. Resolve the selected source before preview and hashing; retain archive-entry and installation-destination checks, source revalidation, and rejection of broken or cyclic links.
- Use the instance's verified client protocol for Java server status handshakes, with a valid fallback when the protocol is unknown. Allow an eight-second network budget and distinguish DNS failures, refused connections, timeouts, malformed replies and interrupted connections. The current validation environment could not directly reach `mc.wblnb.cn`; a successful live check of that server is not claimed.
- Add Windows Setup/MSI welcome and completion flows, an option to open NexaCL after interactive installation, and optional Windows 11 Explorer integration. Silent installation does not start the launcher. Explorer integration is off by default; enabling it explicitly trusts the pinned, dedicated signing certificate in machine-wide Trusted People. It does not add a Root certificate. Reinstallation, rollback and uninstall retain certificate ownership records and preserve preexisting trust.
- Fix Windows directory-junction regression cleanup by removing the junction itself before recursively deleting the fixture.
- Retain Alpha 24's compatibility fix for older account files, including preservation of existing accounts and credentials.

Windows, macOS and Linux x64/ARM64 packages retain the separate native modules and bundled Market Sidecar. Keep the complete installation directory. Publisher GPG signatures and optional Explorer certificate trust are separate from publicly trusted OS code signing and Apple notarization.

## 简体中文

本版精简实例设置，改善本地文件访问与服务器发现，并更新 Windows 安装器。

- 捆绑 Liuli 主题，包含按页面变化的动效，以及账户操作和版本选择区域的材质调整。
- 更新助手兼容 Windows 稀疏 MSIX 注册添加的已知只读条件权限，继续拒绝条件写入授权、未知权限、不受信任的所有者及不支持的 ACE 类型；在 Windows 双架构上验证默认安装、主动启用集成后的真实 NativeAOT 更新助手准入。
- 移除所有内容详情中的通用文件／NBT 查看器及实例导航入口，移除服务器要求与环境匹配编辑表单。命名启动配置和临时覆盖仅在实例开发者模式显示。
- 打开服务器页后自动发现局域网游戏，以“来自局域网的服务器 + 地址”与已保存服务器并列显示，自动去重，可直接加入；不再显示独立发现提示或按钮。发现的临时端点不会写入 `servers.dat`。
- 支持导入和打开有效符号链接或目录联接路径下的普通文件。在预览和计算哈希前解析来源，保留归档条目、安装目标及提交时的来源校验，并拒绝失效或循环链接。
- Java 服务器状态握手优先使用实例已验证的客户端协议号，未知时使用有效的备用协议号；网络超时预算调整为八秒，区分 DNS 失败、拒绝连接、超时、无效响应和连接中断。当前验证环境无法直连 `mc.wblnb.cn`，尚未确认该服务器的实网检测结果。
- Windows Setup／MSI 增加欢迎与完成流程、交互安装结束后启动 NexaCL 的选项，以及可选的 Windows 11 资源管理器集成。静默安装不会启动启动器。资源管理器集成默认关闭；主动启用时，才将固定的专用签名证书加入所有用户共享的 Trusted People，不加入 Root。覆盖安装、回滚和卸载记录证书归属，并保留原有信任。
- 修复 Windows 目录联接回归用例的清理流程，先删除联接本身，再递归清理临时目录。
- 继续包含 Alpha 24 的旧账户文件兼容修复，保留原账户与凭据。

继续提供 Windows、macOS、Linux 双架构发行包，携带分离原生模块和配套 Market Sidecar。请保留完整安装目录。发布者 GPG 签名及可选的资源管理器证书信任，不等同于公开受信任的系统代码签名或 Apple 公证。
