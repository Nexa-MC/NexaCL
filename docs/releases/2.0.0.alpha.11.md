# NexaCL Firefly Alpha 11 · v2.0.0.alpha.11

本版本以 Alpha 10 为基线，继续 Alpha 预览阶段。

- 便携版新增应用内更新：在可写目录中以普通权限运行时，可直接下载并应用匹配当前版本的差分包；继续校验既有发布者签名、版本、平台、文件长度和摘要，差分不可用或损坏时自动回退到已签名的完整包。
- 更新保留中断恢复、失败重试和回滚能力。原始安装版本单独持久化，重启后仍能正确选择更新版本或回滚版本，保留启动参数、用户配置和本地文件。
- 中国大陆隐藏主导航的“安装”入口，并拒绝已隐藏入口的激活与旧导航事件。首页获取游戏的按钮继续打开 Minecraft Launcher 官方引导；资源浏览、本地导入、整合包安装和已有实例设置继续可用，沿用所需本地原版检查及全球正版资格规则。
- 修正原生启动验证中的大陆入口流程，并从发布包排除验证期间产生的安装本地更新日志、事务缓存和版本槽，避免将运行状态打入新安装包。

**旧便携版升级说明：** Alpha 10 及更早便携版没有此次新增的更新入口，需要先下载并手动升级到 Alpha 11 一次，之后才能在启动器内直接更新后续版本。系统安装版继续使用受保护的预装更新程序；便携版请使用普通权限运行，放在可写目录中。

Windows、macOS、Linux 均提供 x64 / arm64 的 NativeAOT 构建。安装包和便携包按系统与架构选择一个即可，差分文件由启动器自动选择。下载和签名更新使用独立更新源 [NexaCL-Update](https://github.com/Nexa-MC/NexaCL-Update/releases/tag/v2.0.0.alpha.11)，源码与反馈入口为 [NexaCL](https://github.com/Nexa-MC/NexaCL)。
