# NexaCL Firefly Alpha 17 · v2.0.0.alpha.17

## 更新中心

- 重做“更新与维护”页面，集中显示当前版本、更新通道、检查状态和可用版本；检查过程中不再清空整页信息。
- 新增独立 Sidecar 更新列表，支持下载安装、失败重试，以及重启后应用。
- Sidecar 更新目录和可执行文件均使用正式发布密钥签名。安装前校验兼容性、大小、哈希及签名；失败保留原版本，不修改 macOS 应用包。
- 发布资源新增六个平台的独立 Sidecar 包及签名目录，随更新源一起同步。

## 按版本显示的新引导

- 按 Sidecar、页面及修订版本记录完成状态，只显示新增或尚未完成的引导内容。
- 每次需要引导时，始终显示欢迎页和完成页；全部完成后不再重复弹出。
- 中途退出会恢复未完成内容；即使已完成最后一个内容页，尚未确认的结束页也不会丢失。

## Market Sidecar 与账户

- 内置更新后的正式签名 Market Sidecar，调整账户、市场与设备授权界面的布局和间距，恢复触屏操作。
- 登录时在客户端显示设备码并支持复制；由用户主动打开授权页面，在网页输入设备码，不再自动拉起带参数的网页。
- 未登录账户页移除“暂不登录”，引导流程保留跳过入口。
- 接入账户等级、经验进度及铭牌选择；通过 Host 的受限认证交换与真实游戏生命周期接口提交活动记录。
- 修复动态 Sidecar 页面状态绑定的隔离与更新，以及设备码剪贴板操作。

## 修复与兼容性

- 补齐更新中心和新引导的英文、繁体中文文案。
- 修复更新卡片内边距与已有布局契约不一致的问题。
- Windows、macOS、Linux 均提供 x64 / arm64 原生构件；保留完整更新包、适用的差分更新及发布签名校验。
