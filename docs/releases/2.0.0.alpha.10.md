# NexaCL Firefly Alpha 10 · v2.0.0.alpha.10

本版本以 Alpha 9 为基线，继续 Alpha 预览阶段。

- 允许直接安装 MRPack、CurseForge 和 Nexa 整合包：中国大陆先检查整合包所需的本地原版，已有完整原版时自动复用；非大陆继续自动下载安装所需游戏依赖。
- 大陆检查覆盖客户端、基础库、资源索引和资源文件。缺少指定版本或文件损坏时，明确提示所需 Minecraft 版本，以及通过 Minecraft Launcher 获取并导入当前游戏目录后重试的步骤，不下载缺失的本体文件。
- 缺少原版的整合包任务保留失败重试入口和已缓存的整合包；导入原版后可直接重试。中断恢复、整合包更新沿用相同地区规则，并继续保留文件校验和事务发布保护。
- 单独的 Java 版下载页继续引导中国大陆用户前往 Microsoft Store 获取 Minecraft Launcher；地区政策独立于界面语言和显示格式，全球正版资格围栏保持生效。

Windows、macOS、Linux 均提供 x64 / arm64 的 NativeAOT 构建。下载和签名更新使用独立更新源 [NexaCL-Update](https://github.com/Nexa-MC/NexaCL-Update/releases/tag/v2.0.0.alpha.10)，源码与反馈入口为 [NexaCL](https://github.com/Nexa-MC/NexaCL)。

安装包与便携包按系统和架构选择一个即可；差分文件由启动器自动选择。完整包、更新清单和差分包均使用既有发布者签名，保留完整包回退和失败重试。
