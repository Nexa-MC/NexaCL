# NexaCL Firefly Beta 1 · v2.0.0.beta.1

发布草稿：代码与发布说明已准备；新仓库迁移、归档与正式发布待 GitHub 权限补齐后执行。

本版本以 Alpha 7 为基线，进入 Beta 阶段。

- 正版资格围栏全球生效：新增或导入非 Microsoft 档案前，须先通过 Microsoft 登录验证拥有 Minecraft Java 版；导入的账户类型或令牌不作为拥有资格的证据。
- 不向中国大陆提供 Minecraft 本体下载。新本体、整合包携带的本体安装及缺失本体文件的自动补全受同一服务政策约束；已有完整本地版本可以继续启动，也可以本地导入。
- 已准备迁往 `Nexa-MC/NexaMC`，承接当前 XSR 代码和 Git 历史；独立更新源为 `Nexa-MC/NexaMC-Updates`，用于更新发现和已签名构件分发，并兼容已知旧源。
- 支持读取整合包在线身份、预览并应用更新；重新检查变更，保留用户修改的内容并处理冲突。
- 下载、安装和更新失败后可从任务卡片重试；失败的下载缓存保留到启动器关闭，以便重试复用完整文件或断点。
- 统一 Windows 11 风格圆环加载动画。首次加载隐藏对应内容并居中显示提示；资源列表追加加载保留现有列表和滚动位置。
- Splash 和任务卡片使用左右布局，支持长任务名、错误信息换行，完善浅深色主题下的操作按钮显示。
- 修复所有账户在登录前准备阶段长时间等待的问题；准备失败可重试。
- 修复安装验证的误拒绝、迁移完成状态提示和确认期间的表单展示，以及 macOS 启动与红绿灯后方绘制问题。
- 官方 Actions 构建继续验证嵌入的 CurseForge API 凭据，发布包保留既有签名与校验规则。

地区政策沿用现有部署国家/系统地区判定，独立于界面语言与显示格式；它不是 IP 地理位置认证。Java、模组、资源包、光影与本地导入仍按各自服务规则提供。

首次迁移可从 `Nexa-MC/NexaMC-Updates` 的发布页手动下载安装 Beta 1；仍固定使用历史更新地址的旧构建需要先完成这次升级。
