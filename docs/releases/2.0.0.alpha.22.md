# NexaCL Firefly Alpha 22

Version: `2.0.0.alpha.22`

## English

### Launching and Java

- Prepare and launch different game instances simultaneously, with separate progress, Java choices and cancellation. A second launch of the same instance is rejected.
- Select version-local Java, including runtimes in nested instance folders. Add portable Java paths relative to the launcher and selection by Java major version.
- Add dedicated Nide8 account compatibility and enforce its Java 8u141 minimum.

### Windows memory cleanup

- Add independent deep-cleanup operations for system working sets, file cache, modified and standby pages, registry cache, page combining and volume flushing, with per-operation results and timing.
- Add the optional **Deep clean at launch** checkbox to the home memory card. Cleanup runs after preflight and before creating the game process. Declining UAC skips cleanup and continues launching; canceling the launch prevents game creation.
- Keep running games protected. Global operations are skipped when a protected game is detected; process-level cleanup remains available.
- Improve cleanup reports and the memory card's layout in small windows. The implementation does not incorporate Mem Reduct source or binaries.

### Instances and content

- Discover LAN games and join or save discovered servers.
- Import HMCL, MCBBS and MultiMC modpacks, add CurseForge, MCBBS and MultiMC export formats, and choose optional pack files individually.
- Allow supported portable exports to carry an explicitly selected launcher distribution and Java runtime. Export launcher-mediated instance start scripts without account credentials.
- Inspect archive contents, resource/shader packs and schematic metadata; browse typed NBT trees and MCA/MCR chunks, including supported external and LZ4 chunk payloads.
- Enable and reorder resource packs through instance settings, preserving unrelated game options and checking pack compatibility.
- Customize new offline accounts with a UUID, local skin/cape and model selection.

### Distribution and development

- Keep the separate native modules and pinned independent Market Sidecar in complete packages.
- Make English the canonical documentation language and provide Simplified Chinese versions of the main guides.
- The feature parity checklist records remaining work; this release does not claim complete parity with every reference launcher.

### Downloads and upgrade

Windows, macOS and Linux packages are provided for x64 and ARM64. Keep the complete installation directory, including native modules, JVM Host, Sidecars and resources; do not replace only the launcher executable.

Memory cleanup is Windows-only. Publisher GPG signatures are independent of Windows Authenticode, Apple Developer ID and notarization.

## 简体中文

### 游戏启动与 Java

- 支持不同游戏实例同时准备并启动，分别管理进度、Java 选择和取消操作；阻止重复启动同一实例。
- 支持版本内 Java，包括实例目录中的嵌套运行时；新增相对启动器目录的便携 Java 路径和指定 Java 主版本选择。
- 增加 Nide8 统一通行证专用兼容，并检查 Java 8u141 最低要求。

### Windows 内存清理

- 深度清理增加系统工作集、文件缓存、修改页与待机页、注册表缓存、内存页合并和卷刷新等独立操作，分别报告执行结果与耗时。
- 主页内存卡片新增「启动前深度清理」，默认关闭。预检通过后、创建游戏进程前请求提权清理；拒绝 UAC 授权会跳过清理并继续启动，取消启动则不会创建游戏进程。
- 继续保护运行中的游戏。检测到受保护游戏时跳过全局操作，仍可进行进程级清理。
- 改进清理报告和小窗口中的卡片布局。独立实现，未复用 Mem Reduct 的源码或二进制。

### 实例与内容管理

- 自动发现局域网游戏，支持加入和保存发现的服务器。
- 支持 HMCL、MCBBS、MultiMC 整合包导入，增加 CurseForge、MCBBS、MultiMC 导出格式，并可逐项选择整合包可选文件。
- 受支持的便携导出可携带明确选定的启动器发行目录和 Java 运行时；可导出不含账户凭据、由启动器管理认证的实例启动脚本。
- 解析压缩包、资源包、光影包和投影文件元数据；查看通用 NBT 树及 MCA/MCR 区块，支持相应外部区块和 LZ4 数据。
- 在实例设置中启用、排序资源包，保留其他游戏选项并检查资源包兼容性。
- 新建离线账户可定制 UUID、本地皮肤/披风和模型。

### 发布与开发

- 完整安装包继续携带分离原生模块及固定版本的独立 Market Sidecar。
- 项目文档以英文为主，主要开发指南同时提供简体中文。
- 功能对照清单仍保留待办，本版不宣称已与所有参考启动器完全对齐。

### 下载与升级

提供 Windows、macOS、Linux 的 x64 / ARM64 安装包和便携包。请保留完整目录中的原生模块、JVM Host、Sidecar 和资源，不要只替换启动器可执行文件。

内存清理仅支持 Windows。发布者 GPG 签名不等同于 Windows Authenticode、Apple Developer ID 或 macOS 公证。
