# NexaCL Firefly Alpha 13 · v2.0.0.alpha.13

以 Alpha 12 为基线，继续 Alpha 预览阶段。

## 稳定性、账户与服务连接

- 修复 Intel Mac 系统能力探测中的原生缓冲区长度错误，解决设置页快速滑动导航时可复现的崩溃。
- 调整 macOS 红绿灯与标题的对齐，清理左上角重复圆角边线，并修正系统菜单中的应用名称。
- 完善 Microsoft 网页授权完成后的 Minecraft 会话交换：对可恢复的连接失败进行有限重试，按失败阶段显示原因，保留真实 TLS 异常；不关闭证书校验。
- 统一 CurseForge 凭据在资源查询、安装目录、模组和整合包安装路径中的传递，修复官方构建已嵌入密钥但安装仍提示缺少密钥的问题。
- 遥测改用独立的原生客户端入口，避免网站浏览器挑战阻断客户端上报；现有遥测开关与隐私策略继续生效。

## 启动与运行日志

- 启动器日志按会话拆分为独立文件，文件名使用时间戳；启动失败时可从 Splash 直接打开当前日志。
- 运行中的会话日志允许安全读取，修复数据迁移预览读取正在使用的日志时失败的问题。
- Minecraft 日志查看器改为紧凑工具栏、保留搜索框的连续阅读区，以及统一的分页和复制操作区；支持按输出来源筛选、选择并复制日志。
- 保留恢复过程中的冲突信息，避免重试或启动失败掩盖仍需处理的安装恢复状态。

## 手柄入场与前台动画

- 仅在检测到前台手柄操作后显示暗色提示；双摇杆向内推动并保持 1 秒后进入全屏入场动画。
- 震动从开始内推动作时启动，按经过时间逐渐增强；支持真实轴力反馈的 Linux 驱动可按动作进度增加阻尼。
- 进入过场前停止反馈；取消、失焦、断连、采样中断或退出启动器时同样停止输出。普通 Windows/macOS 手柄使用设备提供的震动能力，不将震动当作摇杆阻力。
- 修复手柄轮询没有在原生 UI 调度器执行的问题。游戏启动和安静调度期间，只要启动器仍在前台，就保留前台界面动画。
- **手柄模式仍为入场预览，尚未提供模式内的游戏库、导航和启动操作。实物震感和真实阻尼仍需按设备校准。**

## Sidecar 与第三方扩展

- Sidecar 可通过经过哈希校验的文档包使用与启动器相同的 NXML 页面、组件、动态片段和 NSS 样式，并复用状态绑定与异步指令链路。
- 支持对具名界面节点进行插入、修改和替换；模块停用后恢复当前有效的原界面，拒绝过期输入并取消待处理调用。
- 新增独立 Sidecar 页面与首次启动引导页，支持同会话页面导航、继续引导和会话结束后的页面清理。
- 增加产品函数的构建期插桩，以及通过 NFP3 协商、激活和撤销自动函数补丁的能力；NativeAOT 构建沿用相同的插桩与校验流程。
- 扩展仍受签名、能力协商、会话隔离和资源预算约束；本次发布不包含独立 Nexa.Plugin 仓库的 SDK 更新。

## 下载与更新

Windows、macOS、Linux 均提供 x64 / arm64 的 NativeAOT 安装包和便携包。受支持的安装可通过应用内更新升级；发布流程会为最近五个兼容版本生成小于完整包的差分包，差分不可用时回退到经过签名校验的完整包。

Alpha 10 及更早便携版需先手动安装 Alpha 11 或更新版本，再使用应用内更新。测试预发布版本前请备份存档。
