# NexaCL Firefly Alpha 15 · v2.0.0.alpha.15

以 Alpha 14 为基线，本次集中改善界面层级、操作反馈和更新可靠性。

## 界面与操作反馈

- 默认窗口调整为 960×600，保留 810×470 最小尺寸；统一启动页、设置、资源、任务、账户、更衣室和对话框的留白、辅助文字色彩与按钮尺寸。
- 圆环加载新增配套成功／失败动画：闭合圆圈后绘制勾或叉。任务、通知和启动失败使用统一线条；支持减少动态效果，避免重复刷新重播。
- 没有 Microsoft 正版档案时，添加档案直接进入 Microsoft 账户流程；已有正版档案时保留提供方选择。
- 添加档案失败或取消时，结果动画与提示居中、操作按钮位于下方；保留重试与返回流程。
- 版本内容读取时隐藏“总览／游戏设置”占位导航，完成后恢复完整分类，避免加载时显示半成品页面。

## 资源列表

- 优化资源卡片内边距、文字层级、搜索与筛选点击区域，长版本名称支持两行。
- 保持触底追加、已有条目、搜索草稿和滚动位置；修复详情返回时临时重算列数造成的偏移变化。
- 列表结束时显示“没有啦~”，提前计入末尾高度；追加失败时仍可重试，不误显示列表结束。

## 更新与扩展支持

- 修复 GitHub 发布资源跳转处理，改善无法获取更新文件的问题；安装更新失败时补充可定位的日志。
- Host 新增通用滚动观察通知和用户点击触发的 HTTPS 链接入口，为 Sidecar 连续列表和浏览器操作提供基础支持。
- 云账户和市场页面仍由独立 Sidecar 提供，不合并进启动器本体；本次只发布 Host。
- 对照当前源码整理功能文档，补充界面预览和接口说明。

## 下载与更新

提供 Windows、macOS、Linux 的 x64 / arm64 安装包和便携包。发布流程验证安装、启动与更新恢复，并按兼容历史版本生成和校验差分包；不适用差分时使用签名完整包。
