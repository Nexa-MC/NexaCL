# NexaCL Firefly Alpha 9 · v2.0.0.alpha.9

本版本以 Alpha 8 为基线，继续 Alpha 预览阶段。

- 修复更新检查误报失败：独立更新源正常返回、但已是最新版、目录为空或没有所选通道时，正常显示检查结果，不再继续请求旧接口并提示“暂时无法检查更新”。实际网络错误和无效更新信息仍会报告失败。
- 中国大陆 Java 版下载页改为官方启动器引导，提供前往 Microsoft Store 获取 Minecraft Launcher 的入口；已有完整本地游戏仍可导入和启动。Store 中的官方启动器适用于 Windows，macOS / Linux 用户可继续使用完整本地版本。
- 补齐跨新旧仓库的签名差分发布流程，自动查找兼容的历史完整包；完整包发布后可追加已签名差分扩展，保留原有构件和签名，并支持失败重试与完整包回退。

Windows、macOS、Linux 均提供 x64 / arm64 的 NativeAOT 构建。下载、更新和签名分发继续使用独立更新源 [NexaCL-Update](https://github.com/Nexa-MC/NexaCL-Update/releases/tag/v2.0.0.alpha.9)，源码与反馈入口为 [NexaCL](https://github.com/Nexa-MC/NexaCL)。

安装包与便携包按系统和架构选择一个即可；差分文件由启动器自动选择。发布包、更新清单和差分包均使用既有发布者签名，完整包可作为差分不可用时的回退。

本版本保留全球正版资格围栏及中国大陆 Minecraft 本体下载限制。地区政策独立于界面语言与显示格式，沿用现有部署国家/系统地区判定。
