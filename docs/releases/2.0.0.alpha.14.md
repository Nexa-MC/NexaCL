# NexaCL Firefly Alpha 14 · v2.0.0.alpha.14

以 Alpha 13 为基线，本次集中完善本地平台集成、资源管理、运行诊断和整合包使用流程。

## 资源管理与游戏启动

- Windows 启动前核对 JVM Host、所选 Java 和 jvm.dll 的架构；Windows ARM64 上允许匹配的 x64 Host/Java 组合，并检查游戏原生 DLL 的架构信息。
- 支持按实例指定 CPU Sets、进程 QoS 和处理器拓扑策略，包括性能核心、最大缓存域与单 NUMA 域；显式策略在私有 JVM 启动前落实。
- Linux 支持用户级 CPU、内存和磁盘 I/O 配额，并提供可选 GameMode 会话；退出或取消时释放本次请求，不修改系统服务配置。
- 内存紧张时回收可重建的共享缓存，严重压力下协作暂停 Sidecar 激活；结合已知 GPU/统一内存余量限制新增图像资源。
- 根据磁盘实测延迟调整后台并发；计费网络、电池和热状态影响后台工作，明确区分无法探测与已确认的状态。
- Minecraft 内存分析仍保持关闭，不参与启动预检或自动堆内存分配。

## 桌面与本地存储

- Windows 任务栏显示下载进度；截图可调用原生系统分享面板。
- macOS 截图支持 Quick Look，备份与恢复优先尝试 APFS 文件克隆。
- macOS 13 及以上提供 Spotlight 搜索入口及 App Intents 快捷指令，可打开启动页、资源页与设置页；Siri 可用性由系统设置和设备能力决定。
- Linux 窗口菜单新增 Steam 与 Steam/Gamescope 注册入口。选择一个 Steam 用户配置目录并退出 Steam 后写入，保留原快捷方式备份；不覆盖其他用户的配置。
- 在可用且有权限的 Btrfs 子卷或 ZFS 文件系统上，用只读原生快照捕获备份；不支持时保留文件备份。所有备份继续逐文件校验，恢复写入新目录，不回滚正在使用的文件系统。
- 改进 macOS DMG 打包的占用重试；只有验证成功的映像才进入发布产物。

## 安装、公告与体验反馈

- 整合包可直接进入安装流程，完善安装与重试过程中的状态反馈。
- 加入后台公告及启动器公告展示。
- 每逢第 30 次启动提供可关闭的体验问卷，涵盖满意度、性能、稳定性与可选问题描述。
- 修复 Sidecar 动画表单的保留行为，补充原生预览与相关界面翻译。

## 诊断与遥测

- 补充遥测响应耗时、异常类型、调用阶段及经过清理的诊断信息。
- 按单次游戏运行关联 Minecraft、加载器、Java、模组元数据、启动配置、周期样本和退出汇总；可用指标涵盖 CPU、内存、GPU、磁盘 I/O 与进程树。
- 模组清单增加文件哈希、嵌套候选和提供的别名，标记未知、截断或缺失的分页；模组声明不等同于运行时已加载。
- 后台可查看单次运行详情，明确区分配置值、实测零值和未采集值。保持现有遥测授权及预发布策略，不收集账户令牌、个人路径、存档内容或原始日志。
- 内存评估的 CI 采样保留真实观测和能力限制，不把 CI 样本称作个人设备实测。

## 下载与更新

提供 Windows、macOS、Linux 的 x64 / arm64 安装包及便携包。受支持的安装可通过应用内更新升级；差分包按兼容历史版本生成并进行往返验证，不适用时回退到签名完整包。

本次不包含局域网接力、同步和串流、AI 后端，以及 HDR/VRR 等后续显示与输入适配。
