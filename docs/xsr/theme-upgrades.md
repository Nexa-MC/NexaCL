# 同 ID 主题升级

主题清单 ID 是目录中的逻辑身份。导入相同 ID 会准备已有主题的新候选版本，
成功激活、持久化后替换安装项；准备失败、取消或降级确认被拒绝时保留原安装。
相同版本允许重新安装。历史重复安装在成功提交后收敛为一个安装项。

版本比较由 Themes Service 负责：数字段按数值比较，缺少的尾部数字视为零；
同数字版本的正式版高于 `.channel.sequence` 预发布版，通道按序数比较、序号按数值比较。
候选投影携带原版本和降级标记，Desktop 在激活前显示双版本确认框。
Service 的提交（包括预览）也要求明确允许降级，不仅依靠 UI 提示。
候选提交检查原安装与选项修订，禁止把旧候选提交到已变化的安装上。

兼容的选项值沿用，已删除或不再合法的值使用新清单默认值。
安装身份不是资源授权：不同来源路径或种类的主题不继承外部文件授权；
准备阶段不可读取旧授权，成功替换才撤销旧授权和旧目录监视。取消不影响原授权。
内置主题不能被导入包覆盖。

2026-10-30 验证：Themes Service 35 项、Desktop 主题回归 34 项通过。
覆盖数值/预发布版本顺序、相同 ID 更新与重启、降级提交及预览的确认门槛、
弹窗双版本显示及两种决策、等待确认时取消、跨来源授权隔离、旧数据内置 ID 冲突，
以及激活失败时重新固定已提交版本的恢复路径。
