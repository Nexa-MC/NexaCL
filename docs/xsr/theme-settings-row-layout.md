# 主题参数设置行

主题参数编辑区沿用普通设置页的紧凑表单布局：184 DIP 标签列、16 DIP
列间距、右侧自适应控件列、44 DIP 最小行高及同色细分隔线。
开关与分段选择靠右，文本输入占据控件列，数值步进与滑条在同一行。
长标签允许换行，不把滑条单独铺到整张卡片下方。

页面结构继续位于 `ThemeOption.d.nxml`，样式位于 `ThemeSettings.nss`。
控制器保持原有 Dynamic 编辑器标识与顺序；草稿、光标、焦点、拖动中的滑条
和自动保存协议不变。不在控制器内构造新的展示节点。

内置的 color/background/window/video/music 分组通过外部
`ProductCopySettingsTerms.nxml` 显示可读标题，跟随既有本地化；未知主题
分组仍保留其提供的名称。中英文与繁体文案留在本地化资源中。

验证沿用 ThemeOption 回归，覆盖草稿保持、输入组合、自动保存、失败重试、
作用域切换及滑条拖动期间的加载时机。原生主题预览用于检查实际宽窄窗口排版。
