# UI 设计整理（2026-10-27）

使用用户指定的 `@user_865e3592/ui-new`，适配原生 XSR/NXML/NSS，而非引入 Web UI 或远程字体。

- 默认窗口由 850×500 调整为 960×600；保持 810×470 最小尺寸及原有原生边框／托盘恢复行为。
- 内容区使用 24×20 留白；启动页卡片、安装选择和表单采用 4/8 点间距。启动按钮提升至 48 高，资源搜索／筛选为 40 高。
- 复用已有调色板可识别的 `#5e6e82`／`#606c7c` 次要文字颜色，提高浅色可读性，保留深色及自定义主题投影。蓝色仍用于品牌、选中项和主要操作。
- 设置标题强化字重和前景，分组间距 24，表单内部留白 16×8。导航顺序为通用、外观、游戏、Java、网络、存储、系统、隐私、更新、关于；设置键及持久化语义不变。
- 资源卡片高 168，内边距 16×14，虚拟列表的行高同步调整，避免卡片重叠或滚动定位失配。
- 任务、账户、对话框、更衣室及实例管理沿用统一辅助文字颜色；关键按钮增加点击空间。

保留圆环加载、追加列表时保留已有条目、筛选器不被加载页遮挡、减少动态效果及不重复播放列表入场动画的既有契约。不恢复此前移除的信息提示或诊断面板。

验收使用现有真实 Avalonia 离屏渲染工具（受控账户／资源数据），同时检查亮暗主题、大窗口和紧凑窗口；模拟数据不代表实际在线目录或登录账户。

实测回归：960×600 原生资源页从详情返回时，隐藏列表缺少快照曾触发临时列数重算，导致偏移从 3120 跳至 2940。控制器现在保留上次测量的列表视口，直到新布局快照可用；沿用原生追加／重试／返回断言，并补充桌面连续列表回归。长版本名称支持两行，行内操作与名称垂直居中。

验收结果：Release 构建零警告／错误；374 项 Desktop 回归、46 项 Avalonia 后端测试及 72 项目架构检查通过；格式检查通过。亮暗资源原生交互均通过加载、追加、失败重试及详情返回验证。预览包包含 114 张真实渲染 PNG 和 HTML 索引，使用受控数据；Windows/macOS 原生窗口生命周期的最终平台验证继续由 CI 执行。
