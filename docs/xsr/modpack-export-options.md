# 整合包导出选项

按 1.X 的能力迁移内容分类、资源包/光影包/存档等内容筛选、搜索与导出配置复用。
模组只按整类选择，不在页面列出逐文件选项。文件视图分页呈现，避免大整合包创建过多控件。
实例信息与在线整合包共用信息卡片；离线依赖检查及准备期间保留卡片标题。

格式明确分为 MRPack 和 ZIP，不再只改变后缀。MRPack 仍通过生产整合包导入器校验。
ZIP 包含 `.minecraft/` 游戏目录和 `nexa-export.json` 包说明，可以解压后选择该游戏目录，
不是 CurseForge 包，也不走 MRPack 导入器。始终保留本实例的版本描述和父版本描述；
可分别选择游戏核心（含原版）、当前平台运行库和声音/语言等资源文件，默认均关闭。
运行库复用 Library Resolver，核心复用 ClientJar Resolver，资源仅包含当前索引引用的对象。
不扫描或带入其他实例的共享依赖；勾选的依赖缺失时导出失败，需先准备离线依赖。
ZIP 不附带 Java 或启动器，未勾选的依赖仍需启动器下载。
导出配置为版本化 JSON，包含格式、附带依赖选项、相对路径、排除项及包元数据，不保存本机目录和账号信息。
账号文件、密钥、日志、临时文件及链接不因手动勾选而获准导出。
