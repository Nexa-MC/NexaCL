# Native Minecraft management ownership

Instance management, content mutations, identity, server lists, file workspace,
screenshots, world operations, offline readiness and modpack exports execute in
the Minecraft runtime against its canonical process collection, recovery locks,
settings port, task partition and shared cache. Production routers forward typed
commands and queries; the managed public runtime remains available.

Operations use explicit generated numeric dispatch and immutable value contracts.
Platform image cropping and backup storage are reverse asynchronous capabilities.
World edit admission is local to Minecraft: the Darwin advisory-lock implementation
moves to a shared platform source under Platform.Runtime. The backend compiles
that same primitive with its existing public namespace/name for compatibility,
without adding a reference to the platform runtime or service implementations.
The production descriptor remains owned by Minecraft for
the complete transaction. A failed admission cannot produce an unguarded edit.
Screenshot bytes and backup manifests are copied values, never native pointers or
CLR service objects.

Queries preserve existing error contracts. Management snapshots retain recovery
comparison, and all mutations observe the same process/running-world guards as
launch. Shutdown stops admission and drains operations and reverse capabilities
before releasing their owners. Independent-runtime tests cover real mutations,
stale revisions, running-instance rejection and cancellation; production UI and
architecture/AOT checks gate completion.

Production Foundation routes now forward all 37 management operations, including
recovery, export options/export execution, server lists, identity and content
workspace. World snapshot storage and screenshot encoding use acknowledged reverse
capabilities; world editing holds its local platform lock throughout the operation.
Offline-readiness and snapshot query adapters retain their existing cancellation
and friendly-error contracts.

Validation includes an independent NativeAOT caller with actual identity/server/file
edits and stale-revision rejection, screenshot byte exchange and crop admission,
content integrity, trash/restore, world copying with a real session.lock and scoped
snapshot capture/verification/restore. A mutation during a real launched process is
rejected by the same canonical process collection. The 297-shape intermediate
schema and subsequent combined 352-shape schema both pass independent AOT execution;
complete UI AOT/headless/real-window shutdown also pass. The focused managed
management batch passes 37 regressions and the 97-project architecture gate.
