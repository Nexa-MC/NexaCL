# Native Minecraft resource orchestration

Resource search/detail/changelog, favorites, translations, icons, dependency plans,
downloads, instance identification, content updates and online modpack operations
belong to Minecraft. They share the installer, task partition, process collection,
recovery gate, canonical download/work ports and cache already owned there.
Resources and its pure contracts become explicit Minecraft owner/client references.
Production composition forwards typed commands and queries; managed composition
retains its public APIs and concrete implementations.

The owner uses the existing no-redirect described HTTP transport, regional policy,
provider credentials, durable favorites and disk cache. Each admission obtains a
canonical global settings snapshot; source selection and dependency preferences
are cached immutable values, never synchronous reverse calls. Retrying a task
refreshes those values before admitting the retry. Optional custom source ports
use generated typed asynchronous requests. The normal production source is local
to Minecraft and uses the canonical Network HTTP/download transport.

Module close cancels and drains background cache refreshes before disposing HTTP
or icon concurrency resources. No content update may bypass the module's active
process checks or per-root recovery locks. Independent-runtime tests must cover
real provider bytes, dependency planning, durable favorites, exact download hashes,
running-instance rejection, retry/cancellation and physical retirement before this
boundary is accepted.

The download attachment additionally accepts the existing INativeDownloadPort;
the concrete NativeNetworkClient overload forwards unchanged. Independent tests
use a host-owned checking port that asserts the original HTTPS provider admission,
exact length and redirect budget before translating the fixture request to a local
HTTP server and the real native Network downloader. Production uses the concrete
Network client. Its independent download suite separately rejects loopback sources
when resource-host admission is enabled; no test exception enters that rule.
