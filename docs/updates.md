# 更新与事务

`src/modules/updates/` 保存更新契约、发现、事务、原生客户端和 codecs。`nexa-updates` 拥有流程；`Nexa.Update.Helper` 是独立的受保护安装助手。UI 只展示状态并提交意图。

发布者身份固定为 `5701218D69B531E1A7ED35BB6E31F5974A273AEE`，公钥位于根目录 `GPG-PUBLIC-KEY.asc`。完整发布清单规定产品、渠道、版本、运行时、配置、平台文件名、大小和 SHA-256。来源、版本防回退和文件字节都通过准入后才能安装。

差分通过签名的 `Nexa-Delta.json` 选择匹配已安装源版本的平台包；目标字节和完整包摘要受独立约束。差分不可用、基线不匹配或不能重建时，保留经过独立认证的完整包回退。发布脚本必须验证差分重建，不仅检查压缩包能打开。

便携更新与受保护安装使用不同权限路径。受保护助手校验自身安装位置、发布者和操作对象，不接受把任意新下载助手临时提权。事务使用受限对象命名空间、版本化槽位、日志、恢复与激活／回滚；不通过任意路径组合获得写入权限。中断、替换竞态、离线恢复和失败重启由相应平台测试覆盖。

Sidecar 更新有独立的候选、验签、激活和状态，不等于主程序更新完成。更新源同步必须先校验源实际资产，再公开完整目标发布；上传中断的候选保留草稿状态。公开资产不能被同版本重建覆盖。

当前目录迁移不改变用户配置位置、安装目录布局、发布文件名或更新数据格式。
