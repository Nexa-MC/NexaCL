# 源码目录迁移

本次变更将原来散布在根目录和 `native/` 的源码归入 `src/`，按功能组织业务项目与协议；测试按对应功能分组，工具区分编译器、探针和基准。旧项目文档与历史预览附件从当前文档树移除，重新建立现状文档。历史内容仍由 Git 和已公开 Releases 保留。

保持现有 101 个 C# 项目、程序集身份、公开契约、原生导出和十一模块分发。用户配置、安装布局和已公开 Alpha 19 的构件不在这次源码调整中改写。机器依赖基线只移动到 `eng/architecture/project-references.json`，不扩大许可；`projects.json` 记录全部项目位置。

关键适配包括：不再以目录深度推断产品自动插桩；编译工具引用与源码根映射使用新位置；协议生成、NativeAOT 构建、资源链接、测试和 CI 路径统一迁移；解决方案分组对应磁盘结构。

完成标准是项目清单与依赖图保持一致、全部引用路径有效、生成代码不变、完整构建与架构检查通过、自动插桩覆盖实际 UI 闭包，并由六平台 CI 验证原生模块与打包。检查入口见 [测试](testing.md)。验证结果以提交后的工作流和实际执行日志为准，本页不预填成功数字。
