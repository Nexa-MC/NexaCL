# Built-in themes and development examples

BuiltIn contains product themes; Minimal and Advanced provide executable NTP/1 manifest, NSS, and asset examples. Services own package admission, Desktop coordinates application, and Renderer consumes prepared styles. See [theme documentation](../../../../docs/themes.md) for format and security contracts.

Liuli is a separately installable, original glass theme inspired by the visual direction of QQNT Liuli. Its NSS and SVG are authored for NexaCL; see `Liuli/README.md` for attribution, supported options and packaging. It follows the host's light/dark and reduced-motion policies.
